METHODOLOGY AND PROCESSING

LULC pixel centres are spatially tested against the selected administrative geometry. Pixels outside the selected AOI are excluded from area statistics, charts and map rendering. Area is calculated using the source raster's spatial resolution and coordinate reference system.

For projected metre-based rasters, pixel area is calculated from pixel dimensions. Geographic rasters use latitude-adjusted pixel area calculations.
