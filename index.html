Spatial analysis method
The selected region, district or ward is represented by its EA polygons. Raster pixel centres are tested against the selected administrative geometry. Only pixels inside that geometry contribute to the selected-area class counts, areas and percentages.
The repository provides classified GeoTIFF snapshots for 2000, 2005, 2010, 2015, 2020 and 2025. This dashboard interprets the existing class values and calculates statistics; it does not retrain a new satellite-image classifier.
